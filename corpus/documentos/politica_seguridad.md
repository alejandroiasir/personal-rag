# Política de Seguridad de la Información (documento ficticio)

Documento de prueba para el proyecto. Los datos son inventados.

## 1. Contraseñas

1.1. Las contraseñas deben tener un mínimo de 12 caracteres.
1.2. Las contraseñas deben cambiarse cada 90 días.
1.3. No se pueden reutilizar las últimas 5 contraseñas.

## 2. Gestión de incidentes

2.1. Todo incidente de seguridad debe notificarse al Director de Seguridad (CISO) en un plazo máximo de 24 horas desde su detección.
2.2. El registro del incidente debe conservarse durante 3 años.

## 3. Copias de seguridad

3.1. Las copias de seguridad se realizan cada día a las 02:00.
3.2. Las copias se conservan durante 30 días.
3.3. Una restauración de prueba se realiza cada trimestre.

## 4. Acceso remoto

4.1. El acceso remoto a los sistemas internos requiere VPN corporativa.
4.2. El acceso remoto exige autenticación de dos factores (MFA).
4.3. Las sesiones remotas inactivas se cierran tras 15 minutos.

## 5. Dispositivos personales

5.1. Los dispositivos personales no pueden almacenar datos confidenciales.
5.2. Los dispositivos personales que accedan al correo corporativo deben tener bloqueo de pantalla.

# Norma de prevención de riesgos laborales (documento ficticio 08)

Documento de prueba para el proyecto. Los datos son inventados.

1. Alcance. Esta norma aplica a todas las sedes y se revisa anualmente. Referencia interna 279 unidades.
2. Responsables. El responsable del área debe revisar el procedimiento cada año y registrar los cambios.
3. Límites. El límite de referencia es de 340 kilos por operación.
4. Registro. El responsable del área debe revisar el procedimiento cada año y registrar los cambios. Número de expediente 464.
5. Revisión. El personal debe conservar la documentación asociada durante el periodo indicado por el área.
